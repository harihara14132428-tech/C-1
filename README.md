This project demonstrates the use of Structures (struct) in C programming to store and display student information.
The program collects the following details from the user:
Roll Number
Student Name
Marks
It uses a structure named student to group different data types (int, char, and float) under a single variable.
After receiving the input, the program displays all the student details in an organized format.
🛠️ Concepts Used
C Programming
Structures (struct)
Variables and Data Types
scanf() – Getting user input
printf() – Displaying output
Structure Members (. operator)
